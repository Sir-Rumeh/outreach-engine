# outreach-engine

Outreach Engine | Full-Stack AI Automation Tool (Python, FastAPI, Google Gemini API, Tailwind CSS, Threading)

Engineered a high-performance backend automation service using FastAPI and asynchronous background threading to extract lead data and generate hyper-personalized B2B cold outreach messages via the Google Gemini API.

Implemented real-time telemetry and state management, enabling non-blocking pipeline execution, live progress tracking, and graceful mid-process cancellation.

Designed a modern, responsive dashboard interface utilizing Tailwind CSS with real-time status polling and structured CSV export capabilities.
